# Clockx
ClockX is a custom-built digital clock powered by an ESP32-S3. It includes a 2.25-inch TFT display, physical control buttons, a rechargeable battery, a custom-designed PCB, and a 3D-printed enclosure.
# Functions
- Usual Time display
- Alarm
- Stopwatch
- Timer
- Custom rington option
- There are some holes for USB, Buzzer, Battery and display with tolerances of 0.5mm.

# Interesting Fact

- The alarm clock is soo tiny. Its like less then 110mm in all sides.
